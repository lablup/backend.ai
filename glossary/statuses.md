# Glossary: Status sets

The style rules are in the [glossary](../GLOSSARY.md). Korean: [statuses.ko.md](statuses.ko.md)

| English | Meaning | Do not write | Note |
|---|---|---|---|
| activeness status | The status of whether a deployment is active, with the values ACTIVE and INACTIVE. |   |   |
| agent status | The operational status of an agent, with the values ALIVE, LOST, RESTARTING, and TERMINATED. |   |   |
| artifact revision status | The processing status of an artifact revision, with the values SCANNED, PULLING, PULLED, VERIFYING, NEEDS_APPROVAL, AVAILABLE, FAILED, REJECTED. |   |   |
| audit log status | The processing status of an audit log record, with the values success, error, unknown, running, denied. |   |   |
| deployment status | The deployment status in v2, which has the values PENDING, READY, DEPLOYING, SCALING, STOPPING and STOPPED. |   |   |
| endpoint lifecycle | The status representing the lifecycle stages of a deployment endpoint. |   |   |
| endpoint status | The serving status of an endpoint, with values READY, PROVISIONING, HEALTHY, UNHEALTHY, DESTROYING, DESTROYED, DEGRADED. |   |   |
| image role | The usage classification of an image, with values COMPUTE, INFERENCE, SYSTEM. |   |   |
| image status | The status of an image, with values ALIVE, DELETED, PURGING and PURGE_ERROR. | ImageStatusType |   |
| kernel status | The lifecycle status of a kernel, with values PENDING, RESERVED, SCHEDULED, PREPARING, BUILDING, PULLING, PREPARED, CREATING, RUNNING, RESTARTING, RESIZING, SUSPENDED, TERMINATING, TERMINATED, ERROR and CANCELLED. |   |   |
| network type | The type of network used between containers in a session. |   |   |
| route status | The lifecycle status of a route within a deployment. |   |   |
| service catalog status | A bundle of status values for service instances registered in the service catalog. |   |   |
| session status | The lifecycle status of a session, with values such as PENDING, PREPARING, RUNNING, and TERMINATED. |   |   |
| usage mode | A set of purpose values for a vfolder, consisting of general, model, and data. |   |   |
| user status | The status of a user account, with the values active, inactive, deleted, and before-verification. |   |   |
| vfolder operation status | A set of status values that holds both the work status and the delete stage of a vfolder. |   |   |
