## 26.10.0a6 (2026-11-10)

### Breaking Changes
* Stop loading plugin wheels from `./wheelhouse` during discovery; the manager, agent and storage-proxy now load wheels at start only with `allow = true` under `[wheelhouse]` in their config file, from `wheelhouse.path` (default: `./wheelhouse`), and wheels no longer provide CLI commands. ([#16407](https://github.com/lablup/backend.ai/issues/16407))
* Require the etcd key `config/watcher/token` for the agent watcher instead of falling back to the fixed token `insecure` ([#16488](https://github.com/lablup/backend.ai/issues/16488))
* Require the agent RPC authentication keypair settings (`rpc-auth-manager-public-key`, `rpc-auth-agent-keypair`); an agent without them no longer starts. ([#16489](https://github.com/lablup/backend.ai/issues/16489))
* Reject OpenID sign-in callbacks not started from the same browser and ID tokens issued for another issuer or client, and require `openid.issuer` in the OpenID plugin config when `well_known` is not set ([#16553](https://github.com/lablup/backend.ai/issues/16553))
* Require the same deployment-specific token_secret of at least 32 characters in both TOTP hook and webapp configurations before upgrading, and stop startup when a loaded plugin raises a configuration ValidationError instead of silently skipping the plugin. ([#16557](https://github.com/lablup/backend.ai/issues/16557))
* Require etcd authentication: every component now rejects startup unless the etcd `user` and `password` are configured. ([#16564](https://github.com/lablup/backend.ai/issues/16564))
* Remove the webserver's `/config.ini` and `/stats` endpoints and stop serving JavaScript and CSS source maps; the WebUI reads `/config.toml` instead ([#16612](https://github.com/lablup/backend.ai/issues/16612))
* Pass one typed dataclass instead of the request and positional tuples to the `PRE_SIGNUP`, `POST_SIGNUP`, `VERIFY_PASSWORD_FORMAT` and `POST_ENQUEUE_SESSION` hooks, and no arguments to the `PRE_ENQUEUE_SESSION` and `POST_AGENT_HEARTBEAT` hooks, so hook plugins must update their handlers for these events ([#16659](https://github.com/lablup/backend.ai/issues/16659))
* Stop returning the manager and webserver release versions to unauthenticated clients by requiring authentication on the manager `GET /` and dropping the `version` field from the health responses of every component and from the webserver ping response ([#16736](https://github.com/lablup/backend.ai/issues/16736))
