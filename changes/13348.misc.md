Decide backport targets from `.github/maintained-versions.yml` rather than the pull request milestone: a `fix:` pull request goes to every maintained version, and a `Backport:` line in the description names the targets instead — particular versions, or `none`. `/backport <version>` on a merged pull request is the way in afterwards. The registry is kept in step by `scripts/release.sh`, which registers a line when its branch is cut and retires one when its support ends.
