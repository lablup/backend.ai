Decide backport targets from `.github/maintained-versions.yml` rather than the pull request milestone: `fix:` goes to every maintained version, a `Backport:` line in the description adds targets, the `no-backport` label opts out, and `/backport <version>` works on an already-merged pull request. The registry is kept in step by `scripts/release.sh`, which registers a line when its branch is cut and retires one when its support ends.
