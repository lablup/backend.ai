Remove the `HiRedisQueue` message queue implementation and the `use-experimental-redis-event-dispatcher` config field from the manager, agent, storage-proxy, app-proxy-coordinator and app-proxy-worker — `RedisQueue` is now the only transport. A config file that still sets the option to `false` keeps loading with the option ignored, but setting it to `true` now fails config validation, since the transport would otherwise change silently. The wire format is unchanged, so no message is lost across the switch.
