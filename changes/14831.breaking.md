Narrow three organization reads that were open wider than the permission model says. Reading a domain now needs READ on that domain, which every member holds through the `domain_member` role; `GET /v2/resource-groups/{name}/wsproxy-version` is answered within the caller's domain, project and keypair scopes instead of on login alone; and the `project` and `user` filters of a domain search now match a single row each rather than each condition matching a different one.
