Fix thirteen defects in the agent's kernel lifecycle and the manager's scheduler that a multi-node session test rig surfaced: a registry save that failed a concurrent create, a recovery record that silently rebuilt every kernel as a Docker one, a clean that stopped at a container already gone, an unbounded wait on the kernel runner's reply, a port pool whose reuse cooldown and range checks were lost across a restart, a per-request rather than per-node container-creation bound, a cancelled session whose cleanup hook never ran, and a force-terminated session whose volatile network was never given back.
