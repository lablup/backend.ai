Backend.AI workload cluster components are installed in {{ .Release.Namespace }}.

GPU allocation policy: {{ $policy }}
  Pre-flight report: kubectl -n {{ .Release.Namespace }} logs job/backendai-preflight
{{- if eq $policy "bai" }}
  bai-dra allocates every NVIDIA GPU, whole and fractional. On the GPU nodes bai-dra owns:
    NVIDIA DRA driver: gpus.enabled=false (AICR: gpuResourcesEnabledOverride=false); keep
      computeDomains enabled for multi-node NVLink sessions.
    Device plugin: off (gpu-operator devicePlugin.enabled=false, or node label
      nvidia.com/gpu.deploy.device-plugin=false).
{{- else if eq $policy "nvidia-dra" }}
  The NVIDIA DRA driver allocates NVIDIA GPUs; fractions only on a bai-dra fGPU node pool taken
  out of its kubelet plugin (kubeletPlugin.affinity) with nvidia.com/gpu.deploy.device-plugin=false.
{{- end }}
{{- if .Values.managerAccess.tokenSecret }}

Manager access: register a kubeconfig with the token of Secret backendai-manager-token.
  kubectl -n {{ .Release.Namespace }} get secret backendai-manager-token -o jsonpath='{.data.token}' | base64 -d

  The token does not expire. Rotate it periodically and when someone who held it leaves:
    1. kubectl -n {{ .Release.Namespace }} delete secret backendai-manager-token
       (the old token stops working at once)
    2. helm upgrade {{ .Release.Name }} ... (creates the Secret again with a new token)
    3. Put the new token in the Manager's kubeconfig of this compute cluster.
  Or set managerAccess.tokenSecret=false and give the Manager a bound token:
    kubectl -n {{ .Release.Namespace }} create token backendai-manager --duration=720h
{{- end }}

session gateway share. To rotate it, update the Secret and restart both:
  kubectl -n {{ .Release.Namespace }} rollout restart daemonset/node-helper deployment/session-gateway
