# Backend.AI Accelerator Plugin for TPU

Install this package in the same virtual environment as the Backend.AI agents.
The agents then detect TPU devices on their hosts and make them available to
Backend.AI kernel sessions.

```console
$ pip install backend.ai-accelerator-tpu
```

**Note**: The accelerator plugin API is under development and may change with the
Backend.AI agents without prior notice. The plugin may stop working unexpectedly,
and keeping it up to date is your responsibility.
