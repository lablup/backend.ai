# Backend.AI Accelerator Plugin for ROCm

Install this package in the same virtual environment as the Backend.AI agents.
The agents then detect ROCm devices on their hosts and make them available to
Backend.AI kernel sessions.

```console
$ pip install -e <Path to this repository>
```

This open-source edition of the ROCm plugin supports allocating one or more ROCm
devices to a container, slot by slot.
