# Backend.AI Accelerator Plugin for CUDA

Install this package in the same virtual environment as the Backend.AI agents.
The agents then detect CUDA devices on their hosts and make them available to
Backend.AI kernel sessions.

```console
$ pip install backend.ai-accelerator-cuda-open
```

This open-source edition of the CUDA plugin supports allocating one or more CUDA
devices to a container, slot by slot.
