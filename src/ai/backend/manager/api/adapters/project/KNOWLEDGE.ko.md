## 수정

수정의 활성 플래그는 deprecated 다. 비활성화하면 삭제를, 활성화하면 복원을 호출하고, 이미 그 상태면 호출하지 않는다. 나머지 필드는 수정으로 반영한다. 상태는 노드에 담기지 않으므로 시나리오는 활성 플래그로 확인한다.

## 여럿 수정

여럿 수정은 프로젝트마다 단건 수정과 같은 쓰기를 한다. 프로젝트 row 를 수정한 뒤 그 프로젝트가 따르는 자원 정책 공유를 다시 작성한다.

활성 플래그는 항목마다 단건 수정과 같은 기준으로 삭제와 복원을 호출한다. 실패는 항목마다 실패 목록에 담는다.

## 여럿 삭제와 복원

여럿 연산은 호출 전체를 거부하지 않는다. 처리한 프로젝트는 처리된 목록에, 처리하지 못한 항목은 id 와 이유를 실패 목록에 담는다. 여럿 영구 삭제는 없다.

## image commit 을 위한 Container Registry 조회

일반 프로젝트 조회에는 image commit 을 위한 Container Registry 조회가 포함되지 않는다. GraphQL 에서 해당 필드를 요청하면 별도로 일괄 조회한다.

- 프로젝트의 기본 레지스트리를 읽는다. `is_default` 가 설정된 `association_container_registries_groups` 행을
  본다. `groups.container_registry` JSON 은 읽지 않는다.
- 읽기 권한은 프로젝트마다 확인한다. 기본 레지스트리가 없는 프로젝트는 빈 결과를 답한다.
