# session adapter: 배경

규칙은 상위 디렉터리의 `AGENTS.md` 에 있다.

세션은 자기가 속한 프로젝트를 이름으로 참조한다. 따라서 세션 권한은 프로젝트 스코프에 있고, 그 역할을 부여하는 일이 곧 그 사용자를 프로젝트 멤버 목록에 추가하는 일이 된다.

## 조회

필터 없는 전체 조회는 superadmin 역할이 차단한다. 스코프 권한이 차단하는 조회는 스코프를 받는 검색이다.

## 여럿 종료

여럿 종료는 호출 전체를 거부하지 않는다. 처리된 세션은 끝난 상태(취소됨, 종료 중, 강제 종료됨, 건너뜀)와 함께 처리된 목록에, 거부된 세션은 id 와 이유를 실패 목록에 담는다. 이미 끝났거나 없는 세션은 건너뜀으로 처리된 목록에 들어간다.

## 종료 (옛 이름)

옛 종료는 여럿 종료와 같은 처리를 호출하고 응답을 끝난 상태별 목록으로 나눈다. 거부된 세션이 하나라도 있으면 호출 전체를 거부한다.
