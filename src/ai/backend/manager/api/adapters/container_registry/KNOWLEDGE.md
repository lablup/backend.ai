# 컨테이너 레지스트리 어댑터 — 시나리오

규칙은 상위 디렉터리의 `AGENTS.md`에 있다. 여기 적힌 것과 실행 결과가 어긋나면 문장을 먼저
의심한다.

레지스트리는 어느 스코프에도 속하지 않게 만들어지고 행을 지목하는 배선이 하나도 없다. 그래서
이 어댑터의 문은 전역 역할 하나뿐이다. 예외가 허용 프로젝트를 붙이고 떼는 자리로, 그것만
rbac의 관계 동작을 부르므로 권한 그래프가 지킨다. 두 문은 거부하는 것도 집행 스위치에
반응하는 것도 다르므로 절을 따로 둔다.

레지스트리가 소유하는 이미지는 이 문서에 적지 않는다. 이미지는 자기 어댑터를 가지므로
`../image/KNOWLEDGE.md`에 있다.

|---|---|---|---|

| 슈퍼관리자가 아닌 사용자가 만든다 | 전역 역할 없음 | 만들기 | 역할로 거부 |
| 집행을 꺼도 슈퍼관리자가 아니면 못 만든다 | 엔티티 권한 집행 꺼짐, 전역 역할 없음 | 만들기 | 역할로 거부 |

주소 검사가 고치는 경로에만 있고 만드는 경로에는 없다. 같은 값이 만들 때는 들어가고 고칠 때는
거부되므로 고치기 절의 같은 줄과 짝을 이룬다.

주소나 이름이 공백뿐인 요청은 줄로 두지 않는다. 요청 타입이 이미 막으므로 어댑터가 보장하는
것이 아니다.

집행을 끄는 줄은 이 문이 역할이라 스위치가 통하지 않는다는 것을 못박는다. 허용 프로젝트 절의
같은 줄과 결과가 반대인 자리다.

요청 타입이 커서를 받지만 이 훑기는 크기와 건너뛸 수만 읽는다. 커서를 함께 주면 지금은 조용히
버려진다. 줄을 적기 전에 버릴 것인지 쓸 것인지 정한다.

## 고치기

| 시나리오 | 상황 | 요청 | 결과 |
|---|---|---|---|
| 슈퍼관리자가 주소만 바꾼다 | 그 레지스트리가 있음, 전역 역할 있음 | 주소 수정 | 주소는 새 값, 나머지는 그대로 |
| 값을 하나도 주지 않는다 | 그 레지스트리가 있음, 전역 역할 있음 | 빈 수정 | 아무것도 바뀌지 않은 노드 |
| 호스트가 없는 주소로 바꾼다 | 그 레지스트리가 있음, 전역 역할 있음 | 주소 수정 | 주소 형식으로 거부 |
| harbor 종류인데 프로젝트를 비운다 | harbor 레지스트리가 있음, 전역 역할 있음 | 프로젝트 수정 | 프로젝트 값으로 거부 |
| 아무것도 갖지 않은 id를 고친다 | 다른 레지스트리만 있음, 전역 역할 있음 | 주소 수정 | 대상 없음으로 거부 |
| 슈퍼관리자가 아닌 사용자가 고친다 | 같은 레지스트리가 있음, 전역 역할 없음 | 주소 수정 | 역할로 거부 |

주소 검사는 호스트가 있는지만 본다. 스킴은 보지 않는다 — `http`도 `https`도 아닌 주소는 앞에
`http://`가 붙은 뒤 파싱되므로 `ftp://`로 시작하는 주소도, 공백이 섞인 문자열도 통과한다.
거부되는 것은 호스트 자리가 비는 주소뿐이다. 검사가 이대로여도 되는지 정하고 줄을 더한다.

주소와 프로젝트 값은 고친 뒤의 행을 보고 판단한다. 요청이 그 필드를 주지 않아도 저장된 값이
규칙을 어기면 거부되므로, 가운데 두 줄의 상황을 세울 때 요청과 저장된 값을 함께 세운다.

|---|---|---|---|

| 이미 허용된 프로젝트를 다시 넣는다 | 그 연결이 이미 있음, 두 스코프에 권한 있음 | 넣기 | 그대로 있고 중복이 생기지 않는다 |
| 허용된 프로젝트를 뺀다 | 그 연결이 있음, 두 스코프에 권한 있음 | 빼기 | 연결이 사라진다 |
| 없는 프로젝트를 넣는다 | 그 프로젝트가 없음, 레지스트리에 권한 있음 | 넣기 | 프로젝트 없음으로 거부 |
| 연결되지 않은 것만 뺀다 | 그 프로젝트가 연결돼 있지 않음, 두 스코프에 권한 있음 | 빼기 | 연결 없음으로 거부 |
| 지목한 스코프 중 한쪽만 허용된다 | 레지스트리에만 권한 있고 프로젝트에는 없음 | 넣기 | 권한 부족으로 거부 |
| 집행을 끄면 권한 없이도 붙는다 | 엔티티 권한 집행 꺼짐, 아무 권한도 없음 | 넣기 | 연결이 생긴다 |

관계 동작은 엔티티 종류를 선언하지 않아 스코프에서 읽을 것이 없다. 지목한 스코프가 모두
허용해야 실행되고, 여섯째 줄이 그 규칙을 본다.

집행을 끄는 줄이 만들기 절과 반대 결과를 갖는다. 이 문은 역할이 아니라 권한 그래프가 지키므로
스위치가 통한다.

넣기의 중복은 SQL에서 건너뛰므로 오류가 아니고, 빼기는 지목한 것 중 하나도 지워지지 않았을
때만 거부한다. 둘의 비대칭을 두 줄로 나란히 둔다.
