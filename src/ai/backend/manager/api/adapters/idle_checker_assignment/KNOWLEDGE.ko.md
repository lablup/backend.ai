# idle_checker_assignment adapter: 배경

규칙은 상위 디렉터리의 `AGENTS.md` 에 있다. 이 문서와 실행 결과가 어긋나면 문장을 먼저 의심한다.

할당은 스코프와 유휴 검사기를 잇는 relation 이다. 쓰기는 양쪽 엔티티의 권한을 모두 검사한다. 여럿 연산은 항목마다 단건 쓰기를 따로 실행한다.

## 여럿 영구 삭제

권한이 없는 사용자에게는 할당 id 를 찾는 단계가 없는 id 와 같은 응답을 준다. 할당이 있는지 드러내지 않기 위해서다. superadmin 에게는 없는 id 요청에 대상 없음으로 응답한다.

여럿 연산은 호출 전체를 거부하지 않는다. 처리한 할당은 처리된 목록에, 처리하지 못한 항목은 id 와 이유를 실패 목록에 담는다.

할당 id 는 데이터베이스가 생성한다. 시나리오는 superadmin 한 명으로 할당을 검색해 id 를 얻은 뒤 호출자 자격으로 호출한다.
