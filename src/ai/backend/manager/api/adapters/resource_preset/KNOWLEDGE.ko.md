## 여럿 수정

여럿 수정은 자원 그룹을 변경하지 않는다. 자원 그룹은 프리셋 공개 대상을 변경하므로 단건 수정으로만 변경한다.

## 여럿 영구 삭제

여럿 연산은 처리하지 못한 항목 때문에 호출 전체를 거부하지 않는다. 처리한 프리셋은 처리된 목록에, 처리하지 못한 항목은 id 와 이유를 실패 목록에 담는다.
