# artifact adapter: 배경

규칙은 상위 디렉터리의 `AGENTS.md` 에 있다. 이 문서와 실행 결과가 어긋나면 문장을 먼저 의심한다.

아티팩트는 어느 스코프에도 속하지 않게 생성된다. 아티팩트 하나를 수정하고 삭제하고 복원하는 호출은 권한 그래프가 보호하고, id 목록으로 여럿을 삭제하고 복원하는 옛 호출은 전역 역할이 보호한다.

공통 계약(대상 존재, 여럿 구성)은 프레임워크 계약 테스트가 확인한다. 이 문서에는 연산마다 대표 성공과 대표 실패, 그리고 아티팩트 규칙이 만드는 차이만 적는다.

## 여럿 삭제와 복원

여럿 연산은 호출 전체를 거부하지 않는다. 처리한 아티팩트는 처리된 목록에, 처리하지 못한 항목은 id 와 이유를 실패 목록에 담는다.

## id 목록으로 여럿 삭제와 복원

여럿 연산이 생기기 전의 호출이다. 옛 REST 경로와 GQL mutation 이 호출한다.
