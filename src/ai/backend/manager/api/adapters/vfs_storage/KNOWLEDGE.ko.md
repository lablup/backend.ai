# vfs_storage adapter: 배경

규칙은 상위 디렉터리의 `AGENTS.md` 에 있다. 이 문서와 실행 결과가 어긋나면 문장을 먼저 의심한다.

VFS storage row 는 global 에만 속하여 생성된다. 하나나 여럿을 지정해 수정하거나 영구 삭제하는 호출은 그 row 에 부여된 권한을 검사한다. 그 권한은 global 에서만 나오므로 superadmin 만 통과한다.
