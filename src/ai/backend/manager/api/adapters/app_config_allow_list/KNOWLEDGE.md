# app_config_allow_list 어댑터 — 시나리오

규칙은 상위 디렉터리의 `AGENTS.md`에 있다. 여기 적힌 것과 실행 결과가 어긋나면 문장을 먼저
의심한다.

허용 항목은 등록된 이름 하나를 스코프 종류 하나에 여는 행이고, 그 스코프의 조각이 병합에서
어느 자리에 서는지를 정하는 순위를 함께 갖는다. 정의와 마찬가지로 어느 스코프에도 속하지
않아 역할이 닿지 않는다. 만들기와 전체 훑기는 전역 역할이 지키고, 하나를 읽고 고치고 지우는
문은 권한 그래프가 지키지만 항목에 이르는 역할이 없으므로 결과는 같다 — 슈퍼관리자는
지나가고 그 밖의 사용자는 거부된다. 두 문이 서로 다른 것으로 거부하므로 짝을 따로 적고,
권한 받은 사용자 줄은 세우지 않는다.

순위가 조각이 아니라 여기에 있다는 것이 이 관심사의 권한 설계다. 값의 소유자는 자기 조각의
순위를 올릴 수 없다. 순위가 병합에 어떻게 보이는지는 `../app_config/KNOWLEDGE.md`가 본다.

고칠 수 있는 것은 순위뿐이다. 이름과 스코프 종류는 항목의 정체이므로 바꾸려면 지우고 다시
만든다. 항목이 사라지면 그 아래 조각이 함께 사라진다.

이 어댑터에는 soft delete가 없다. 지우면 행이 사라지고 되살리는 문도 없다.
