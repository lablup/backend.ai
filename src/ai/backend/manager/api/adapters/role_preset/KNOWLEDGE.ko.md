# role_preset adapter: 배경

규칙은 상위 디렉터리의 `AGENTS.md` 에 있다. 이 문서와 실행 결과가 어긋나면 문장을 먼저 의심한다.

역할 프리셋(이하 프리셋)은 global 스코프에 생성된다. 수정, 삭제, 복원, 영구 삭제, 권한 항목 추가와 제거는 프리셋에 대한 권한 그래프가 검사한다. 아무 역할도 받지 않은 사용자는 global 에서 나오는 권한이 없으므로 거부된다. 이 문서는 쓰기 연산과 검색을 적는다. 생성과 검색 외의 읽기는 아직 적지 않았다.

공통 계약(대상 존재, 여럿 구성)은 프레임워크 계약 테스트가 확인한다. 이 문서에는 연산마다 대표 성공과 대표 실패만 적는다.

## 검색

- `scope_id` 에 값이 있는 프리셋은 global 프리셋뿐이다. domain, project, user 프리셋은 seed 와 API 모두 `scope_id` 를 비워 두므로 그 타입의 모든 스코프에 역할을 생성한다.
- `scope_type` 필터는 저장된 `scope_type` 과 비교한다. `global` 로 검색하면 API 가 `scope_type` 을 `public` 으로 반환하는 프리셋을 포함해 global 프리셋이 모두 반환된다.
