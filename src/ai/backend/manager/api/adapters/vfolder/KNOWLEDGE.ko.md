# vfolder adapter: 배경

규칙은 상위 디렉터리의 `AGENTS.md` 에 있다.

개인 vfolder 는 생성한 사용자의 스코프에 생성된다. 그래서 vfolder 를 생성할 권한은 그 사용자 자신에게 적용된다. vfolder 가 놓일 스토리지 호스트는 도메인과 키페어 정책이 함께 허용해야 한다.

## vfolder 접근 권한

vfolder 는 프로젝트 아래에 있다. 개인 vfolder 는 그 사용자의 개인 프로젝트에, 프로젝트 vfolder 는 그 프로젝트에 있다. 공유는 다른 스코프가 제한을 두고 vfolder 를 빌려 받는 방식이다. vfolder 에 접근할 수 있는지는 vfolder 를 가진 스코프에 역할이 vfolder 읽기를 허용하는지로 정해진다.

## 여러 vfolder 를 한 번에 읽기

다른 엔티티가 참조하는 vfolder 들을 id 목록으로 한 번에 읽는다. 응답은 id 마다 한 항목씩 입력 순서대로 오고, 호출 전체가 거부되지는 않는다. 항목마다 단건 vfolder 읽기와 같은 기준으로 따로 판정한다.

superadmin 이 아닌 사용자에게는 없는 id 도 권한 부족으로 거부된다. vfolder 가 없다는 사실은 권한 없는 사용자에게 드러나지 않는다. 빈 값은 superadmin 만 본다.

## 수정

수정은 이름, 클론 가능 여부, 기본 마운트 권한을 변경한다. 이름은 vfolder 를 가진 스코프 안에서 겹치지 않아야 한다.

## 여럿 수정, 삭제, 복원

여럿 연산은 호출 전체를 거부하지 않는다. vfolder 마다 단건 vfolder 연산과 같은 기준으로 따로 판정해, 처리한 vfolder 는 처리된 목록에, 처리하지 못한 항목은 id 와 이유를 실패 목록에 담는다. 삭제와 복원은 같은 권한 검사를 한다. 여럿 영구 삭제는 이 형태가 아니다.
