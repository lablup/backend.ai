# rbac adapter: 배경

규칙은 상위 디렉터리의 `AGENTS.md` 에 있다. 이 문서와 실행 결과가 어긋나면 문장을 먼저 의심한다.

지금은 역할 쓰기만 적는다. 역할은 한 스코프에 속하고, 역할을 수정하는 호출은 그 스코프의 권한 그래프가 검사한다. 대상 역할은 호출한 사용자가 속하지 않은 도메인에 둔다. superadmin 이 아닌 사용자의 호출은 아무 권한도 없는 사용자로 실행한다.

## 수정

deprecated `status` 는 수정 뒤에 처리한다. DELETED 는 삭제로, 삭제된 역할에는 ACTIVE 를 복원으로 보낸다. 이미 그 상태면 아무것도 하지 않고 INACTIVE 는 반영하지 않는다.

## 여럿 수정

deprecated `status` 는 역할마다 단건과 같은 기준으로 처리한다. 삭제와 복원에서 실패한 역할은 그 이유로 실패 목록에 들어간다.

## 여럿 삭제, 복원, 영구 삭제

여럿 연산은 호출 전체를 거부하지 않는다. 처리한 역할은 처리된 목록에, 처리하지 못한 항목은 id 와 이유와 함께 실패 목록에 담긴다.
