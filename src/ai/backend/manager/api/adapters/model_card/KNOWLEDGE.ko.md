## 수정

모델 카드는 프로젝트에 놓인 vfolder 에 붙는다. 모델 카드를 생성한 사용자와 호출자는 다르다. 권한은 모델 카드가 놓인 프로젝트에서 받는다. 수정은 수정된 모델 카드를 최소 자원 요구와 함께 읽어 응답하므로 읽기 권한도 필요하다.

## 영구 삭제

영구 삭제는 모델 카드 row 를 삭제한다. 옵션을 주면 모델 카드가 붙은 vfolder 를 휴지통으로 옮긴다.

## 여럿 영구 삭제

여럿 연산은 호출 전체를 거부하지 않는다. 처리한 모델 카드는 처리된 목록에, 처리하지 못한 항목은 id 와 이유를 실패 목록에 담는다. 영구 삭제된 모델 카드의 최소 자원 요구는 모델 카드와 함께 삭제되어 처리된 목록에 담지 않는다.
