# 세션 그룹 어댑터 — 시나리오

규칙은 상위 디렉터리의 `AGENTS.md`에 있다. 여기 적힌 것과 실행 결과가 어긋나면 문장을 먼저
의심한다.

세션 그룹은 프로젝트와 소유자 아래에 생긴다. 그래서 세션 그룹 하나를 읽는 문은 권한 그래프가
지키고, 전체 검색은 전역 superadmin 역할이 지킨다.

세션 그룹은 두 가지다. 사용자가 만든 세션 그룹과, 배포가 레플리카 그룹을 만들 때 함께 생겨
그 레플리카 그룹이 참조하는 세션 그룹이다. 뒤의 것은 배포와 함께 관리된다. 사용자에게 내놓는
읽기(하나 읽기, 여럿 읽기, 스코프 검색)는 배포의 레플리카 그룹이 참조하는 세션 그룹을 권한이
있어도 없는 것으로 답하고, 영구 삭제는 사용 중이라는 것으로 거부한다. 전체 검색만 두 가지를
함께 보여준다.

공통 계약(대상 존재, 일괄 구성, 페이지)은 프레임워크 계약 테스트가 확인한다. 여기에는 연산마다
대표 성공과 대표 실패, 그리고 세션 그룹 규칙이 만드는 차이만 적는다.

## 하나 읽기

| 시나리오 | 상황 | 요청 | 결과 |
|---|---|---|---|
| 권한을 받은 사용자가 사용자가 만든 세션 그룹을 읽는다 | 프로젝트에 사용자가 만든 세션 그룹 하나, 그 프로젝트에서 세션 그룹 읽기 권한을 받은 사용자 | id로 조회 | 그 세션 그룹 |
| 아무 권한도 받지 않은 사용자가 읽는다 | 같은 세션 그룹, 아무 권한도 받지 않은 사용자 | id로 조회 | 권한 부족으로 거부 |
| 권한을 받은 사용자가 배포의 레플리카 그룹이 참조하는 세션 그룹을 읽는다 | 배포의 레플리카 그룹이 참조하는 세션 그룹, 그 프로젝트에서 세션 그룹 읽기 권한을 받은 사용자 | id로 조회 | 대상 없음으로 거부 |

마지막 줄에서 사용자는 그 세션 그룹에 대한 읽기 권한도 갖는다. 그래서 거부 이유가 권한이 아니라
대상 없음이어야 한다.

## 여럿 읽기

| 시나리오 | 상황 | 요청 | 결과 |
|---|---|---|---|
| 권한을 받은 사용자가 두 가지 세션 그룹을 함께 읽는다 | 같은 프로젝트에 사용자가 만든 세션 그룹과 배포의 레플리카 그룹이 참조하는 세션 그룹, 그 프로젝트에서 세션 그룹 읽기 권한을 받은 사용자 | 두 id 목록으로 조회 | 요청한 순서대로 사용자가 만든 세션 그룹, 빈 값 |
| 아무 권한도 받지 않은 사용자가 사용자가 만든 세션 그룹을 읽는다 | 사용자가 만든 세션 그룹 하나, 아무 권한도 받지 않은 사용자 | id 목록으로 조회 | 그 자리가 권한 부족으로 거부 |
| 슈퍼관리자가 어느 세션 그룹의 것도 아닌 id를 읽는다 | 아무 권한도 받지 않은 슈퍼관리자 | 그 id 목록으로 조회 | 그 자리가 빈 값 |

여럿 읽기는 호출 전체를 거부하지 않고 자리마다 답한다. 배포의 레플리카 그룹이 참조하는 세션 그룹은
없는 세션 그룹과 같은 빈 값으로 답한다.

없는 id의 줄은 슈퍼관리자가 부른다. 권한 검사는 id마다 권한 그래프를 보는데, 그래프에 없는 id는
권한을 확인할 수 없어 일반 사용자에게는 권한 부족으로 답한다. 검사를 통과하는 사람이어야 읽기의
답(빈 값)을 볼 수 있다.

## 전체 검색

| 시나리오 | 상황 | 요청 | 결과 |
|---|---|---|---|
| 슈퍼관리자가 한 프로젝트의 세션 그룹을 전체 검색으로 찾는다 | 같은 프로젝트에 두 가지 세션 그룹, 아무 권한도 받지 않은 슈퍼관리자 | 그 프로젝트로 걸러 전체 검색 | 두 세션 그룹 모두 |
| 슈퍼관리자가 아닌 사용자가 전체 검색한다 | 같은 세션 그룹들, 그 프로젝트에서 세션 그룹 읽기 권한을 받은 사용자 | 전체 검색 | 역할로 거부 |

전체 검색의 문은 권한 그래프가 아니라 역할이다. 그래서 슈퍼관리자 줄의 행위자가 슈퍼관리자다.
다른 시나리오가 심은 세션 그룹과 섞이지 않게 프로젝트로 거른다.

## 스코프 검색

| 시나리오 | 상황 | 요청 | 결과 |
|---|---|---|---|
| 권한을 받은 사용자가 자기 프로젝트로 검색한다 | 그 프로젝트에 두 가지 세션 그룹, 다른 프로젝트에 사용자가 만든 세션 그룹, 그 프로젝트에서만 세션 그룹 읽기 권한을 받은 사용자 | 그 프로젝트 스코프로 검색 | 그 프로젝트에서 사용자가 만든 세션 그룹만 |
| 권한을 받지 않은 프로젝트로 검색한다 | 다른 프로젝트에서만 세션 그룹 읽기 권한을 받은 사용자 | 권한을 받지 않은 프로젝트 스코프로 검색 | 권한 부족으로 거부 |
| 세션 그룹을 만든 사용자가 자기 스코프로 검색한다 | 두 프로젝트에 자기가 만든 세션 그룹 하나씩, 첫 프로젝트에 배포의 레플리카 그룹이 참조하는 세션 그룹, 둘째 프로젝트에 다른 사용자가 만든 세션 그룹, 자기 스코프에서 세션 그룹 읽기 권한을 받은 그 사용자 | 자기 사용자 스코프로 검색 | 두 프로젝트에서 자기가 만든 세션 그룹만 |
| 다른 사용자의 스코프로 검색한다 | 같은 세션 그룹들, 첫 프로젝트에서만 세션 그룹 읽기 권한을 받은 사용자 | 세션 그룹들을 만든 사용자의 스코프로 검색 | 권한 부족으로 거부 |
| 사용자 스코프와 프로젝트 스코프를 함께 넘긴다 | 같은 세션 그룹들, 자기 스코프와 둘째 프로젝트에서 세션 그룹 읽기 권한을 받은 세션 그룹들을 만든 사용자 | 자기 사용자 스코프와 둘째 프로젝트 스코프로 함께 검색 | 자기가 만든 세션 그룹 둘과 둘째 프로젝트에서 다른 사용자가 만든 세션 그룹 |

스코프 하나라도 권한이 없으면 나머지를 보여주지 않고 검색 전체를 거부한다.

스코프 여럿은 OR로 합친다. 마지막 줄에서 자기가 만든 첫 프로젝트의 세션 그룹은 사용자 스코프로만,
다른 사용자가 만든 세션 그룹은 프로젝트 스코프로만 닿는다. 그래서 둘 다 나와야 합친 것이다.

## 영구 삭제

| 시나리오 | 상황 | 요청 | 결과 |
|---|---|---|---|
| 세션 그룹을 만든 사용자가 그 세션 그룹을 지운다 | 한 프로젝트에 멤버 세션 둘을 가진 사용자가 만든 세션 그룹과 배포의 레플리카 그룹이 참조하는 세션 그룹, 자기 스코프에서 세션 그룹 영구 삭제 권한을 받은 세션 그룹들을 만든 사용자 | 사용자가 만든 세션 그룹을 영구 삭제 | 그 세션 그룹의 id. 세션 그룹과 그 그래프 노드가 사라지고, 멤버 세션 둘은 세션 그룹 id가 비워진 채 남는다 |
| 같은 사용자가 배포의 레플리카 그룹이 참조하는 세션 그룹을 지운다 | 같은 세션 그룹들과 같은 사용자 | 배포의 레플리카 그룹이 참조하는 세션 그룹을 영구 삭제 | 사용 중이라는 이유로 거부. 두 세션 그룹 모두 남는다 |
| 읽기 권한만 받은 사용자가 지운다 | 같은 세션 그룹들, 자기 스코프에서 세션 그룹 읽기 권한만 받은 세션 그룹들을 만든 사용자 | 사용자가 만든 세션 그룹을 영구 삭제 | 권한 부족으로 거부. 두 세션 그룹 모두 남는다 |
| 아무 권한도 받지 않은 사용자가 지운다 | 같은 세션 그룹들, 아무 권한도 받지 않은 세션 그룹들을 만든 사용자 | 사용자가 만든 세션 그룹을 영구 삭제 | 권한 부족으로 거부. 두 세션 그룹 모두 남는다 |

세션 그룹과 그래프 노드가 사라진 것, 멤버 세션이 남은 것은 답에 나오지 않는다. 테스트가 실행 뒤
데이터베이스에서 세션 그룹 수, 세션 그룹 노드 수, 세션 그룹이 있는 세션과 없는 세션의 수를 센다.

배포의 레플리카 그룹이 참조하는 세션 그룹 줄에서 사용자는 그 세션 그룹에 대한 영구 삭제 권한도 갖는다.
그래서 거부 이유가 권한이 아니라 사용 중이어야 한다.

읽기 권한 줄은 영구 삭제가 읽기 권한으로 통과하지 않는다는 것을 보인다. 아무 권한도 없는 줄과
짝을 이룬다.

## 아직 적지 않은 것

- 삭제 표시된 세션 그룹이 기본 검색에서 빠지고, 삭제 시각으로 걸렀을 때만 나오는 것. 세션
  그룹에 삭제 표시를 쓰는 연산이 아직 없어 그런 세션 그룹을 심을 수 없다. 세션 그룹 삭제
  연산이 들어오면 시나리오로 옮긴다.
- 영구 삭제와 동시에 다른 트랜잭션이 그 세션 그룹을 배포의 레플리카 그룹에 붙이는 경우. 가드는 아직
  커밋되지 않은 연결을 보지 못한다. 연결이 먼저 커밋되면 영구 삭제가 FK 위반으로 실패하고 ops가
  FK 위반 오류(409)로 답한다. 영구 삭제가 먼저 커밋되면 연결 쪽이 FK 위반으로 실패한다. 시나리오
  하나가 트랜잭션 둘을 겹쳐 돌릴 수 없어 표에 두지 않는다.
