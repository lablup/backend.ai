분류는 질의 정의를 묶는 이름이다. 정의와 같이 어느 스코프에도 속하지 않게 만들어지므로 어떤
역할을 받아도 개별 분류에 권한이 생기지 않는다. 문은 정의와 같은 세 갈래다 — 읽기와 훑기는
인증만 보고, 만들기는 전역 역할이 지키고, 지우기는 권한 그래프가 지키는데 닿는 역할이 없다.

고치는 문이 없다. 이름이나 설명을 바꾸려면 지우고 다시 만드는 수밖에 없다. 그래서 정의
문서에 있는 "값을 생략하면 바뀌지 않는다" 계열의 줄이 여기에는 없다.

분류를 가리키는 정의는 `../prometheus_query_preset/KNOWLEDGE.md`에 있다. 여기서는 분류를
