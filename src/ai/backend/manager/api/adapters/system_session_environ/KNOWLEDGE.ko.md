# 시스템 세션 환경변수 adapter: 배경

규칙은 상위 디렉터리의 `AGENTS.md` 에 있다. 이 문서와 실행 결과가 어긋나면 문장을 먼저 의심한다.

시스템 세션 환경변수 row 는 public 스코프, 도메인 스코프, 프로젝트 스코프 중 하나에 생성된다. 이 adapter 는 모든 row 를 검색하는 호출, 지정한 스코프 안에서 검색하는 호출, 값 출처 목록을 읽는 호출, row 를 생성하는 호출, row 의 키를 변경하는 호출, row 를 삭제하는 호출과 복원하는 호출, row 를 영구 삭제하는 호출, id 로 여러 row 를 읽는 호출을 제공한다.

검색은 전역 superadmin 역할 검사로 보호된다. 세션에 실제로 주입되는 row 를 선택하지 않고, 스코프와 삭제 여부에 관계없이 조건에 맞는 row 를 모두 반환한다.

id 로 여러 row 를 읽을 때는 row 마다 권한을 검사한다. 모든 사용자는 public 스코프의 row 를 읽을 수 있고, 도메인과 프로젝트의 관리자는 그 도메인과 프로젝트의 row 를 읽을 수 있다. 관리자가 아닌 구성원은 도메인과 프로젝트의 row 를 읽을 수 없다.

## 스코프 없는 검색

monitor 역할은 전역 superadmin 역할 검사에서 읽기만 통과한다. REST handler 와 GQL resolver 는 adapter 를 호출하기 전에 superadmin 만 통과시키므로, monitor 역할의 검색은 adapter 를 직접 호출할 때만 통과한다.

## 값 출처 목록

값 출처는 row 가 아니라 manager 가 제공하는 목록이므로 호출은 로그인 여부만 확인하고 목록을 반환한다. row 의 값 출처는 이 목록의 이름으로 반환되고, 검색 조건에도 이 이름을 사용한다.

## id 로 여러 row 읽기

여러 row 읽기는 호출 전체를 거부하지 않고 항목마다 응답한다.

없는 id 는 superadmin 과 그 밖의 사용자에게 서로 다르게 응답한다. 권한 검사는 id 마다 권한 그래프를 검사하는데, 그래프에 없는 id 는 권한을 확인할 수 없어 superadmin 이 아닌 사용자에게는 권한 부족으로 응답한다. 그 검사를 통과하는 superadmin 만 빈 값을 받는다.
